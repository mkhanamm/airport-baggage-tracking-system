# ✈️ Airport Baggage Tracking System
 Project Overview: 
The Airport Baggage Tracking System is a web-based application designed to simulate real-time tracking of airport luggage from check-in to final delivery..
The system features a dual-dashboard architecture including a user interface and a staff management portal for efficient baggage monitoring and updates.

Checkout the site:  
👉 https://mkhanamm.github.io/airport-baggage-tracking-system/

The project focuses on improving airport baggage handling efficiency, reducing lost luggage issues, and providing a structured tracking workflow.

##  Key Features
- Dual dashboard system with User and Staff portals
- Real-time (simulated) baggage tracking across airport stages
- Staff interface for status updates and workflow management
- Advanced search and filtering for baggage monitoring
- Interactive and user-friendly tracking interface
- Structured baggage lifecycle tracking system
